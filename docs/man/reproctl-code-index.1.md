# NAME

reproctl-code-index - code intelligence index management

# SYNOPSIS

**reproctl code-index** **help**

# DESCRIPTION

Manage jcodemunch code-intelligence indexes for the monorepo. Subcommands for index creation, update, and status reporting will be added in follow-on issues.

## Subcommands

**help**
: Show usage summary and exit 0.

# EXAMPLES

reproctl code-index help
: Show usage summary.
