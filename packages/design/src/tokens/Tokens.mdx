# Design Tokens

The `@repro/design` token system provides a consistent vocabulary for spacing, color,
typography, elevation, motion, and interaction styles. **Always import tokens from
`@repro/design`** — never hardcode raw values.

```tsx
import { color, spacing, textStyles, shadow, radius, transition, focusRing } from '@repro/design'
```

### Raw palette (`colors`)

The full Tailwind palette is available as `colors` for product-specific edge cases
(syntax highlighting, element inspector, etc.). **Prefer semantic `color.*` tokens
for all standard UI.**

```tsx
import { colors } from '@repro/design'
colors.blue['500'] // only for product-specific values with no semantic equivalent
```

## Spacing

A 9-step scale where every value is a multiple of 4 (except `xs` at 2px).

```tsx
import { spacing } from '@repro/design'
<Block padding={spacing.md} gap={spacing.sm} />
```

<div style={{ display: 'flex', flexDirection: 'column', gap: 8, marginTop: 8 }}>
  {Object.entries(spacing).map(([name, value]) => (
    <div key={name} style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
      <div style={{ width: 64, fontSize: 13, fontWeight: 600, flexShrink: 0 }}>{name}</div>
      <div style={{ width: 40, fontSize: 11, color: '#64748b', flexShrink: 0 }}>{value}px</div>
      <div style={{ width: value, height: 16, backgroundColor: '#3b82f6', borderRadius: 2, minWidth: value === 0 ? 1 : undefined }} />
    </div>
  ))}
</div>

**Types:** `SpacingToken` (key), `SpacingValue` (value)

### Line height

| Token | Value | Use case |
|-------|-------|----------|
| `tight` | 1 | Single-line UI labels, badges |
| `normal` | 1.25 | Headings |
| `relaxed` | 1.5 | Body text, captions |

### Font family

| Token | Value | Use case |
|-------|-------|----------|
| `sans` | `sans-serif` | Default UI text |
| `mono` | `monospace` | Code, technical values |

## Motion

### Durations

```tsx
import { duration, easing, transition } from '@repro/design'
```

| Token | Value | Use case |
|-------|-------|----------|
| `fast` | 100ms | Micro-interactions, hover/focus feedback |
| `normal` | 200ms | Default UI transitions |
| `slow` | 300ms | Larger-area transitions |

### Easings

| Token | Value | Use case |
|-------|-------|----------|
| `default` | ease-in-out | Most UI transitions |
| `linear` | linear | Progress bars, marquees |
| `easeOut` | ease-out | Toasts, dropdowns |

### Transition presets

Ready-to-use CSS transition strings:

```tsx
<Block transition={transition.default} />
```

| Token | Value |
|-------|-------|
| `default` | `all 200ms ease-in-out` |
| `fast` | `all 100ms ease-in-out` |
| `transform` | `transform 100ms ease-in-out` |
| `opacity` | `opacity 200ms ease-in-out` |

**Types:** `DurationToken`, `EasingToken`, `TransitionToken`

## Interaction

### Focus ring

```tsx
import { focusRing, focusWithinRing } from '@repro/design'
<Block component="button" {...focusRing()} />
<Block component="button" {...focusRing('danger')} />
<Block component="label" {...focusWithinRing()}>
  <input />
</Block>
```

Available contexts:

<div style={{ display: 'flex', gap: 16, marginTop: 8, marginBottom: 16, flexWrap: 'wrap' }}>
  {Object.entries(focusRingTokens).map(([name, tokens]) => (
    <div key={name} style={{ display: 'flex', flexDirection: 'column', alignItems: 'center', gap: 8 }}>
      <div style={{ width: 48, height: 48, borderRadius: 8, backgroundColor: name === 'inverted' ? '#1e293b' : 'white', border: '1px solid #e2e8f0', outline: tokens.outline, outlineOffset: tokens.outlineOffset }} />
      <div style={{ fontSize: 13, fontWeight: 600 }}>{name}</div>
    </div>
  ))}
</div>

- `focusRing(context?)` — applies `:focus-visible` outline to the element itself
- `focusWithinRing(context?)` — applies `&:has(:focus-visible)` outline to a container when a descendant receives focus

**Type:** `FocusRingContext`
