# Autobot single-track review-ui-quality contract

## Inputs

- Read the diff, the `run-plan.md`, and the surfaced UI behavior.

## Outputs

- Write `review-output.md` with clarity, polish, and authored-vs-generic quality findings.

## Pass / Fail

- Pass when the UI is ready for user-facing review.
- Fail when the UI still needs polish or contract alignment.

## Constraints

- Keep the flow single-track per issue.
