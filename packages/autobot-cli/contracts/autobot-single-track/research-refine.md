# Autobot single-track research-refine contract

## Inputs

- Read the latest `run-plan.md`, the issue context, and any explicit follow-up questions.

## Outputs

- Write the refined research notes or plan deltas that remove uncertainty for the next single-track pass.

## Pass / Fail

- Pass when the next planning pass can proceed cleanly.
- Fail when the work still needs broader discovery.

## Constraints

- Keep the flow single-track per issue.
