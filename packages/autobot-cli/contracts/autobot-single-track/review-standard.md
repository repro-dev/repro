# Autobot single-track review-standard contract

## Inputs

- Read the diff, the `run-plan.md`, the `smoke-test-result.md`, and the current issue context.

## Outputs

- Write `review-output.md` with correctness, clarity, and merge-readiness findings for the changed diff and smoke test.

## Pass / Fail

- Pass when the change is ready for merge review.
- Fail when the change still needs agent fixes.

## Constraints

- Keep the flow single-track per issue.
