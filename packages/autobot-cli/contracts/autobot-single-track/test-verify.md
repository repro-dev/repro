# Autobot single-track test-verify contract

## Inputs

- Read the implementation diff, the `run-plan.md`, and the verification target.

## Outputs

- Write the smoke-test and typecheck evidence that proves the single-track change works.

## Pass / Fail

- Pass when the focused tests and typechecks succeed.
- Fail when the behavior still regresses or remains unverified.

## Constraints

- Keep the flow single-track per issue.
