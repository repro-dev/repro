# Autobot single-track test-verify contract

## Inputs
- Read the implementation diff, the run plan, and the verification target.

## Outputs
- Run the targeted checks that prove the single-track change works.

## Pass / Fail
- Pass when the focused tests and typechecks succeed.
- Fail when the behavior still regresses or remains unverified.

## Constraints
- Keep the flow single-track per issue.
