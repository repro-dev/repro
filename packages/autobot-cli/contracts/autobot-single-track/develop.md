# Autobot single-track develop contract

## Inputs

- Read the approved `run-plan.md`, `context.md`, `test-plan.md`, and the tracked single-track phase contracts.

## Outputs

- Write the smallest safe code diff and matching test updates for one issue.

## Pass / Fail

- Pass when the requested change is implemented and verified.
- Fail when the change needs a broader plan revision.

## Constraints

- Keep the flow single-track per issue.
