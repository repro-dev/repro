# Autobot single-track prepare contract

## Inputs

- Read the queued issue, `context.md`, the current `test-plan.md`, and any prior issue artifacts.

## Outputs

- Write the preparation context that feeds single-track classification and planning.

## Pass / Fail

- Pass when the run is ready for classification and planning.
- Fail when the issue lacks the minimum context needed to continue.

## Constraints

- Keep the flow single-track per issue.
