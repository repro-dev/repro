# Autobot single-track review-correctness-security contract

## Inputs

- Read the diff, the `run-plan.md`, and the issue context.

## Outputs

- Write `review-output.md` with correctness, safety, and security findings.

## Pass / Fail

- Pass when the change is safe and correct.
- Fail when the change needs a targeted fix.

## Constraints

- Keep the flow single-track per issue.
