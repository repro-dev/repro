# Autobot single-track reconciliation contract

## Inputs

- Read the implementation outcome, verification evidence, and any `review-output.md` notes.

## Outputs

- Reconcile the run state and decide whether the single-track issue is complete.

## Pass / Fail

- Pass when the run can be marked complete.
- Fail when more single-track work remains.

## Constraints

- Keep the flow single-track per issue.
